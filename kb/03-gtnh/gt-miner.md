# GTNH: GregTech Miner (LV → IV)

> **Source:** https://wiki.gtnewhorizons.com/wiki/Miner_(GT5U), https://wiki.gtnewhorizons.com/wiki/Advanced_Miner_II
> **Last updated:** 2026-05-16

## Машины

| Машина                 | Тир | Радиус скана | Энергия       |
|------------------------|-----|--------------|----------------|
| Basic Miner            | LV  | 4×4 чанка    | 32 EU/t       |
| Advanced Miner         | MV  | 12×12 чанков | 128 EU/t      |
| Advanced Miner II      | EV  | 32×32 чанков | 2048 EU/t     |
| Pump (для жидкостей)   | LV+ | колонна вниз | 16 EU/t       |

Машина ставится сверху bedrock-области и сама долбит вниз, дроп идёт в
свой top-slot или в подключённую трубу.

## Что нужно для автоматизации

- **Топливо/EU** — энергию подаём кабелем сверху/сбоку.
- **Output** — Conveyor cover на боку → Chest → ME Interface (или сразу ME).
- **Trigger** — машина сама работает, пока есть руда; «закончила» = нет дропов и звуковой эффект.

## Сценарий робота-операт. `robot_miner.lua`

Цель: автоматически разворачивать майнер на новой точке.

```
state machine:
  idle      → бэк присылает {x,y,z,dim, mode=ADVANCED}
  moving    → робот идёт (waypoints или GPS)
  placing   → ставит miner блок, кладёт hopper+chest, втыкает кабель
  waiting   → опрашивает chest: если empty 5 мин подряд → done
  unloading → suck() из chest, drop() в base-chest
  returning → шаги обратно к базе
  idle
```

## Когда «майнер закончил»?

Эвристика:

- 5 минут подряд `chest.contentsEmpty == true` и `miner.disabled == true`.
- Или явный сигнал из `gt.machine` ⟶ редко доступен через OC.

Лучше — таймер «работает не больше 4 ч» + проверка инвентаря каждые 2 мин.

## Сетка работ

На бэке держим таблицу `mining_jobs(id, dim, x, y, z, status, started_at, finished_at)`.
Когда оператор в UI добавляет точку — создаётся row + задача OC.

## Подводные камни

- **Bedrock** иногда выпирает выше — миннер не пробьёт. Робот должен
  уметь обнаружить «не работает» и сообщить.
- **Чанки**: миннер не работает в незагруженных чанках. Поставить
  Chunk Loader блок или дождаться, пока игрок рядом.
- **Жидкости** при пробое каверны — поставить рядом Drain или Pump.
- **EU vs Steam** — у нас MV+ предполагает EU; для Steam‑миннера (HSU)
  отдельная логика подачи пара.

## Альтернатива: Quarry-style

Если в моде есть IC2 Quarry / RoC excavator — логика робота та же:
поставить, дождаться, забрать. Полиморфизм держим в типе `miner_kind`
в БД.
